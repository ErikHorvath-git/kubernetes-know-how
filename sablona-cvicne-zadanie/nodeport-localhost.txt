================================================================================
  PRÍSTUP K NODEPORT SERVICE CEZ localhost:<port>  (minikube docker driver)
================================================================================

Problém:
  V minikube s docker driverom beží klaster vo VM/kontajneri. NodePort 30080
  je otvorený na minikube IP (napr. 192.168.49.2:30080), NIE na hostiteľskom
  localhost. Preto `curl http://localhost:30080` zlyhá.

Riešenie:
  socat — sieťový most z hostiteľa na minikube VM. localhost:<host-port>
  sa preposiela na minikube-ip:<nodePort>.


--------------------------------------------------------------------------------
  POSTUP
--------------------------------------------------------------------------------

1) Inštalácia socat (raz)
-------------------------

  sudo dnf install -y socat        # Fedora / RHEL
  sudo apt install -y socat        # Debian / Ubuntu

  Ak je už nainštalovaný:
    "Package socat-X.X.X-X.fcXX.x86_64 is already installed."


2) Spustenie tunela
-------------------

  socat TCP-LISTEN:3000,fork,reuseaddr TCP:$(minikube ip):30080 &

  Význam parametrov:
    TCP-LISTEN:3000           počúva na localhost:3000
    fork                      pre každé spojenie vytvorí child proces
    reuseaddr                 nemusíš čakať na uvoľnenie portu po reštarte
    TCP:$(minikube ip):30080  cieľ — minikube VM na NodePort 30080
    &                         spustí na pozadí, vráti PID napr. [1] 1048838


3) Test
-------

  curl -I http://localhost:3000

  Výstup by mal začínať:
    HTTP/1.1 200 OK
    Server: nginx/...

  V prehliadači otvor:
    http://localhost:3000


--------------------------------------------------------------------------------
  TOK DÁT
--------------------------------------------------------------------------------

  browser http://localhost:3000
         ↓
  socat (počúva :3000 na hoste)
         ↓
  $(minikube ip):30080            ← reálny NodePort vo VM
         ↓
  Service (NodePort, selector app=...)
         ↓
  Pod (kontajner)


--------------------------------------------------------------------------------
  MAPOVANIE PORTOV
--------------------------------------------------------------------------------

  Ľavá strana (host)         Pravá strana (cluster)
  TCP-LISTEN:3000     ─►     TCP:$(minikube ip):30080

  Môžeš zvoliť ľubovoľný host port (3000, 8080, 8888, ...).
  Pravá strana MUSÍ sedieť s `nodePort:` v svc.yaml.


--------------------------------------------------------------------------------
  ALTERNATÍVY (ak nechceš socat)
--------------------------------------------------------------------------------

  A) minikube service (najjednoduchšie, otvorí prehliadač s tunelom)
       minikube service exam-app-svc -n exam-meno

  B) kubectl port-forward (obchádza NodePort — ide priamo na pod)
       kubectl -n exam-meno port-forward svc/exam-app-svc 3000:80


--------------------------------------------------------------------------------
  SPRÁVA BEŽIACEHO SOCAT-U
--------------------------------------------------------------------------------

  # vidieť bežiace background jobs (socat má ID [1])
  jobs -l

  # zabit socat keď skončíš
  kill %1
  # alebo cez PID:
  kill 1048838

  # overiť že počúva na porte 3000
  ss -tlnp | grep :3000


--------------------------------------------------------------------------------
  PREŽITIE PO ZAVRETÍ TERMINÁLU
--------------------------------------------------------------------------------

  Defaultne socat zomrie keď zavrieš terminál (je viazaný na shell).
  Ak má prežiť:

    nohup socat TCP-LISTEN:3000,fork,reuseaddr TCP:$(minikube ip):30080 \
      > /tmp/socat.log 2>&1 &

  alebo po spustení s &:
    disown


--------------------------------------------------------------------------------
  ČASTÉ CHYBY
--------------------------------------------------------------------------------

  +------------------------------+------------------------------------------+
  | Chyba                        | Príčina                                  |
  +------------------------------+------------------------------------------+
  | Address already in use       | Na hostiteľskom porte 3000 už niečo beží |
  |                              | (React dev server, Grafana, ďalší socat) |
  |                              | → použi iný port alebo zabi proces       |
  +------------------------------+------------------------------------------+
  | Connection refused           | minikube je stopnutý                     |
  |                              | → minikube start                         |
  +------------------------------+------------------------------------------+
  | Hangs forever, no response   | Pod ešte štartuje / readinessProbe falíí |
  |                              | → kubectl get pods, počkaj na Running    |
  +------------------------------+------------------------------------------+
  | minikube ip vráti error      | minikube nebeží                          |
  |                              | → minikube status                        |
  +------------------------------+------------------------------------------+


--------------------------------------------------------------------------------
  PORT < 30000 (nodePort mimo defaultu)
--------------------------------------------------------------------------------

  Ak musíš mať nodePort: 3000 (a nie len localhost:3000):
    1) reštart minikube s rozšíreným rozsahom:
         minikube delete
         minikube start --extra-config=apiserver.service-node-port-range=3000-32767
    2) v svc.yaml: nodePort: 3000
    3) socat TCP-LISTEN:3000,fork,reuseaddr TCP:$(minikube ip):3000 &
